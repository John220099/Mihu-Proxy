## about

Mihu proxy is a simple utility proxy written in nodejs java-script for minecraft bedrock 1.21.94.

---
## how to use
- Install nodejs ```v22.19.0``` is recommended [link](https://nodejs.org/en/download).
- Set up for the proxy : 
```bash 
git clone https://github.com/John220099/Mihu-Proxy.git
cd Mihu-Proxy
npm install
```
- After that type ```npm start``` to start the proxy.
- after joining open chat.
- for list of modules type ````/modules````.
- to enable or disable a module ````/ExampleModule```` (change the ExampleModule text).
